# Sarcio for WordPress — downloads

The Sarcio plugin lets a visitor report a bug from the page it happens on,
drafts a fix, and lets you approve it from your WordPress admin. This
repository holds the plugin's release files for a manual install while its
listing in the WordPress plugin directory is pending.

**Install:** download `sarcio.zip` from the latest release, then in your
WordPress admin go to **Plugins → Add New Plugin → Upload Plugin**, choose the
file, click **Install Now** and **Activate Plugin**. Open **Sarcio** in the
left menu and click **Connect to Sarcio**.

Each release carries the zip, a copy named by version, and a `.sha256`
checksum. Documentation and plans: https://www.sarcio.io/wordpress

The plugin is GPL-2.0-or-later; its licence is inside the zip.
